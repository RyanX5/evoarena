# EvoArena

A simulation where agents fight and evolve over time using neural networks and genetic algorithms.

## How to Run

install dependencies:

```
pip install -r requirements.txt
```

then run:

```
python main.py
```

## Project Structure

- `simulation/` - agent, arena, and neural network code
- `visualization/` - pygame rendering
- `tests/` - unit tests
- `config.py` - settings

## Tech

- Python
- NumPy
- Pygame

## Notes

This is still a work in progress. Right now agents just move around randomly, next step is getting the neural networks hooked up and adding combat + evolution.
